# Known Limitations

## Model Limitations

- Performance decreases under poor lighting conditions
- Certain visually similar diseases remain difficult to distinguish
- Predictions are less reliable for crops outside trained categories

## System Limitations

- WhatsApp media compression can reduce image quality
- Gemini fallback introduces higher latency during low-confidence cases
- External API failures may temporarily impact weather and mandi responses

## Deployment Constraints

- Hugging Face Spaces free-tier limitations affect scalability
- Twilio sandbox mode limits concurrent production-style usage
